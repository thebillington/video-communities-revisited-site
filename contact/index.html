About this website

The site is a static website: plain HTML, CSS and a little JavaScript, built from open data files by a small Python script and published through GitHub Pages. The map data is open and downloadable. The site is designed to keep working after the funded period ends. See the accessibility statement and privacy note for details, or ask us for the source files.

Video Communities Revisited

Video Communities Revisited is a research project on the role of physical screen media — VHS, Betamax, DVD, rental shops, collectors, swap meets and boutique labels — in forming communities in Britain, past and present.
